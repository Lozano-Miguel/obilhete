# O Bilhete — Project Memory

## What is this?
A web app where users enter their Letterboxd username and get:
- Beautiful visual stats (genre breakdown, decades, countries, ratings)
- AI-generated personality tag ("melancholic arthouse wanderer")
- Movie + book recommendations powered by Gemini AI

## Stack
- Next.js 14 App Router + TypeScript
- Tailwind CSS + Framer Motion
- Recharts (charts) + react-simple-maps (world map)
- Supabase (Postgres — caching layer)
- Gemini 1.5 Flash (recommendations + personality tag)
- TMDB API (film metadata enrichment)
- Letterboxd scraper (axios + cheerio + cookie jar)
- Vercel (deployment)

## Design System

## Data Pipeline (on profile request)
1. Check Supabase cache (24h TTL) → serve instantly if fresh
2. scrapeProfile() → display name, avatar, total films
3. scrapeFilms() → all watched films with slugs (paginated)
4. scrapeRatings() → RSS feed → ratings map
5. mergeRatings() → attach ratings to films
6. enrichFilms() → TMDB API → genres, director, cast, country, language, poster
7. buildProfileStats() → compute all chart data
8. getRecommendationsAndTag() → Gemini → 6 movies + 4 books + personality tag
9. upsertCachedProfile() → save everything to Supabase
10. Return full payload

## Scraper Status
- Using axios + tough-cookie + axios-cookiejar-support
- Warm-up request to letterboxd.com/ before scraping (establishes session)
- 800ms delay between film pages
- Browser-like headers + Referer

## API Routes
- POST /api/profile → full pipeline, returns CachedProfile + cached: boolean
- POST /api/recommendations → refresh only recommendations (uses cached films)
- GET /api/og/[username] → OG image using satori + @vercel/og

## Pages
- / → Landing page (Hero + HowItWorks + total profiles counter)
- /[username] → Profile page (stats + charts + recommendations)

## Supabase Schema
Table: cached_profiles
- id: UUID PK
- username: TEXT UNIQUE
- last_fetched_at: TIMESTAMPTZ
- profile: JSONB (LetterboxdProfile)
- stats: JSONB (ProfileStats)
- recommendations: JSONB (Recommendation[])
- films: JSONB (FilmEntry[])
- created_at: TIMESTAMPTZ

## TypeScript Types (types/index.ts)
- LetterboxdProfile: username, displayName, avatarUrl, totalFilms
- FilmEntry: title, year, slug, letterboxdId, userRating, tmdbId,
             genres, director, cast, country, language, posterUrl
- ProfileStats: totalFilms, ratedFilms, avgRating, genreBreakdown,
                decadeBreakdown, countryBreakdown, languageBreakdown,
                ratingDistribution, topDirectors, topActors, personalityTag
- Recommendation: title, year, type, reason, matchScore, posterUrl, author
- CachedProfile: id, username, lastFetchedAt, profile, stats,
                 recommendations, films

## Known Issues / Decisions
- Letterboxd has no public API — using scraper
- Cloudflare 403 blocking naive requests → using cookie jar session
- html2canvas replaced with satori + @vercel/og for share card
- personalityTag generated by Gemini (not computed locally)
- Server components call lib functions directly (not own API routes)
- ScraperAPI as fallback if cookie jar approach fails
- Gemini language: all output in Portuguese (personalityTag + reasons)
- Ratings: user has no ratings, ratingDistribution will be all zeros — hide rating section from UI if ratedFilms === 0
- Books do not have posterUrl — use a placeholder book cover in UI
